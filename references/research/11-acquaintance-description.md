# 罗素第二项内在张力：accept_limited

可有限接受为1912认识论的两项共同要求之间的理论张力：**命题组成须有亲知基础，而知识又能超出直接经验。**这不是自相矛盾；描述分析正是作者协调两者的方案。若指标只允许“作者未解决的矛盾”，则不应计入。

已比对冻结EXTRACTION及10号记录：原有归纳张力追问经验推广的证成，本项追问我们如何理解关于未亲知对象的命题，任务不同。它与既有描述分析共享背景，不因此新增行为程序。

本轮直接读[《哲学问题》第五章](https://www.gutenberg.org/files/5827/5827-h/5827-h.htm)：网页211–274全章，并读第四章末204–210。定位为本次网页行号，不是印刷页码。

- 213–221：亲知不经推理；描述知识依赖真理知识，物理桌子并非直接亲知对象。
- 239–249：亲知不限感官，还包括共相；描述知识涉及存在且唯一符合描述者。
- 250–264：俾斯麦例区分所谈本人、各人实际采用的描述与实际命题组成。
- 268–274：作者同时保留构成的亲知要求和超出私人经验的知识，并暂不处理全部反对意见。

协调关键是：所谈对象不必自身成为我们实际理解的命题组成。亲知要素可构成描述，支持关于未亲知对象的知识；这不自动证明对象存在、描述唯一适用或断言为真。构成条件与证成条件必须分开。

建议未来版本仅补为：“1912年命题构成的亲知要求与描述知识超出直接经验的要求，由描述分析加以协调；存在、唯一性及真理根据仍须另证。”

亲知不能等同日常熟悉某人；俾斯麦自我亲知例有条件；不能将1912立场固定为罗素终身观点。本轮为英语电子转录核读，未作印本校勘或新增行为测试。
